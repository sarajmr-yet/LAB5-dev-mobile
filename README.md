#  Android Converter App (Tabs + Fragments)

This project is an Android application developed in **Java** using **Fragments, TabLayout, and ViewPager2**.

---

##  Features

- Two tabs (Tabs navigation):
  - Temperature Conversion (°C ↔ °F)
  - Distance Conversion (KM ↔ Miles)
- Real-time calculation after clicking OK
- Input validation
- Navigation between fragments using swipe or tabs
- Exit confirmation dialog when pressing back or "Quitter"

---

## Temperature Fragment

- Choose conversion:
  - C → F
  - F → C
- Enter value
- Display result
